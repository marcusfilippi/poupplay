# Poup! Seu Futuro Financeiro

que educação financeira não está na grade curricular obrigatória do ensino fundamental e ensino médio. Matérias como o da InfoMoney mostram que o número de jovens endividados dobrou de 2016 à 2024. Isto é o espelho de um país que não foca em realmente capacitar o jovem para a vida adulta, e que a desigualdade social é enorme. O projeto tem como objetivo acessibilizar e tornar atrativa a educação financeira, tornando os jovens mais conscientes e responsáveis sobre suas atitudes financeiras.

Dado este problema, estamos fazendo uma plataforma chamada "Poup!"

Criar uma plataforma acessível e gamificada de educação financeira para jovens.
